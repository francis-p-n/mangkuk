What you have taught it

When you tell the checker it has something wrong, it is kept here rather than forgotten at the end of the shipment. Nothing you record changes a verdict on its own — a person applies these deliberately, with a report of everything that would change in front of them.

    Making these permanent

    Download the file, put it in the project folder, then ask for the report. It names every shipment whose verdict would change, and marks the ones where a difference would stop being reported.

    python tools/apply_overrides.py

    When the report looks right, --write turns each correction into a case in the test suite, so what you decided here keeps being checked long after this shipment has sailed.
